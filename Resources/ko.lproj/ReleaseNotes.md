# 릴리스 노트

## 1.1.6 — 2026-09-29

- 클립보드 기록을 일시 중지하면 메인 패널과 기록 목록에 배지를 표시하고 다시 시작하는 방법을 안내합니다.
- 수동 클립보드 동기화에서 키체인에 저장된 암호를 다시 입력하지 않고 사용할 수 있습니다.
- 클립보드 기록의 항목 수 제한을 필터 메뉴에서 관리 영역으로 옮기고 적용된 필터 수에 포함하지 않습니다.
- 클립보드 이미지의 텍스트 및 QR 코드 인식에 전체 스위치를 추가했습니다. 끄면 저장된 인식 결과는 지우지만 이미지는 유지합니다.
- 클립보드 관리 영역에서 데이터베이스, 백업, 첨부 파일의 실제 디스크 사용량을 확인하고 즉시 정리와 데이터베이스 압축을 실행할 수 있습니다.
- 부드러운 스크롤 설정에서 감시 중, 손쉬운 사용 권한 필요, 감시 시작 실패를 구분해 표시합니다.
- 자주 쓰는 문구를 AES-GCM으로 암호화해 저장합니다. 기존 평문 JSON은 다음 사용 시 이전됩니다.
- 이퀄라이저 설정을 현재와 직전 두 개만 보관해 오디오 콜백의 안전성을 유지하면서 메모리 증가를 막습니다.
- 시스템 리소스 경고의 대기 시간을 앱 재시작 후에도 유지해 같은 상태의 반복 알림을 방지합니다.
- 설정 화면과 메뉴 막대의 리소스 백분율 계산을 통일했습니다. 기록 그래프는 방향키로 탐색할 수 있고 코어별 값은 VoiceOver에서 읽을 수 있습니다.
- `menutools://` 링크로 장면과 빠른 동작을 실행할 수 있어 Raycast와 단축어에서 사용할 수 있습니다.
- 빠른 동작 이름의 약어를 올바르게 변환해 `flushDNS`가 `flush-dns`로 해석됩니다.
- 설정 화면의 성공, 실패, 정보 안내를 통일해 오류가 성공처럼 보이지 않도록 했습니다.
- 스크린샷 편집기에 실행 취소, 인식 텍스트 복사, 주석 지우기, 저장, 취소 단축키를 추가하고 아이콘 버튼의 손쉬운 사용 레이블을 보완했습니다.
- 스크린샷 기록에서 파일명 검색, 처음 여덟 건 이후의 항목 펼치기, 촬영 시각 확인이 가능합니다. 기록 삭제 전에 확인하며 이미지 파일은 지우지 않습니다.
- 스크린샷 자르기, 회전, 주석 지우기와 추가를 실행 취소하거나 다시 실행할 수 있으며 최대 30단계를 보관합니다.
- MenuTools 자체 패널이 보일 때는 부드러운 스크롤이 패널 안의 원래 스크롤을 바꾸지 않습니다.
- 앱별 오디오가 예상치 않게 5초 동안 무음이면 보호된 음원일 수 있다고 안내합니다. 오디오 경로는 바꾸지 않으며 실제 보호 음원 검증은 아직 필요합니다.
- Finder 우클릭 메뉴가 MenuTools에서 선택한 언어를 따르고 실행 중 언어 변경도 즉시 반영합니다.
- Finder 우클릭 메뉴에서 클립보드 이미지 결과와 터미널 사용 가능 여부를 캐시하고 이미지 디코딩에 상한을 두어 큰 이미지나 다중 선택 시 지연을 줄입니다.
- 플러그인 센터에 의존 관계를 표시합니다. 자동화 플러그인의 실제 의존성을 선언해 필요한 플러그인을 끈 뒤 장면이 조용히 실패하지 않도록 합니다.
- Finder 명령을 꺼도 시스템 확장 기능이 제거되지는 않는다는 점과 완전히 제거하는 위치를 플러그인 센터에 안내합니다.
- 배터리 성능이 80% 미만이거나 macOS가 서비스를 권장하면 경고합니다. 7일 대기 시간은 재시작 후에도 유지되며 배터리가 없는 Mac에는 표시하지 않습니다.
- 설정 화면에 ⌘F 전체 검색, 사이드바 키보드 탐색, 손쉬운 사용 레이블을 추가했습니다.
- 클립보드 기록에서 텍스트, 이미지, 링크, 파일, 서식 있는 텍스트, PDF의 보관 기간을 각각 설정할 수 있습니다.
- Finder 확장 기능과 메인 앱의 버전 표시를 모두 1.1.6으로 통일했습니다.
- Finder 우클릭 진단에서 손쉬운 사용 권한과 자동화 권한을 구분하고 실제 설정 디렉터리의 쓰기 가능 여부만 보고합니다.
