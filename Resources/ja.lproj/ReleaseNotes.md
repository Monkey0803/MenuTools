# リリースノート

## 1.1.6 — 2026-09-29

- クリップボードの記録を一時停止すると、メインパネルと履歴一覧にバッジを表示し、再開方法も案内します。
- 手動同期では、キーチェーンに保存済みのパスフレーズを再入力せずに使えるようになりました。
- クリップボード履歴の件数上限をフィルターから管理欄へ移し、フィルターの適用数にも含めないようにしました。
- クリップボード画像の文字・QR コード認識に一括スイッチを追加しました。無効にすると認識結果を削除しますが、画像は残ります。
- クリップボード管理欄にデータベース、バックアップ、添付ファイルの実使用容量を表示し、即時クリーンアップとデータベースの圧縮に対応しました。
- スムーズスクロール設定で、監視中、アクセシビリティ権限不足、監視の起動失敗を区別して表示します。
- 定型文を AES-GCM で暗号化して保存します。従来の平文 JSON は次回の利用時に移行します。
- イコライザー設定は現在と直前の二つだけ保持し、音声コールバックの安全性を保ちながらメモリ増加を防ぎます。
- システムリソース警告のクールダウンを再起動後も保持し、同じ状態の重複通知を防ぎます。
- 設定画面とメニューバーのリソース使用率を統一しました。履歴グラフは矢印キーに対応し、コア別の値を VoiceOver で読み上げられます。
- `menutools://` リンクからシーンとクイック操作を起動でき、Raycast やショートカットから利用できます。
- クイック操作名の略語を正しく解析し、`flushDNS` は `flush-dns` になります。
- 設定画面の成功・失敗・情報メッセージを統一し、エラーを成功と見間違えないようにしました。
- スクリーンショット編集に、取り消し、認識文字のコピー、注釈の消去、保存、キャンセルのショートカットを追加し、アイコンボタンのアクセシビリティラベルも補いました。
- スクリーンショット履歴でファイル名検索、八件を超える表示、撮影時刻の確認ができます。履歴の消去には確認が必要で、画像ファイルは削除しません。
- 切り抜き、回転、注釈の消去と追加を取り消し・やり直しでき、最大 30 ステップを保持します。
- MenuTools 自身の表示中のパネル内では、スムーズスクロールが元のスクロールを変更しなくなりました。
- アプリ別音量で予期しない無音が五秒続くと、保護された音源の可能性を案内します。音声経路は変更せず、保護音源での実機検証は未完了です。
- Finder のコンテキストメニューは MenuTools 内で選んだ言語に従い、実行中の言語変更も反映します。
- Finder のコンテキストメニューで画像結果とターミナルの利用可否をキャッシュし、画像デコードの上限を設けて大きな画像や複数選択時の遅延を減らします。
- プラグインセンターに依存関係を表示します。自動化の実際の依存先を宣言し、必要なプラグインの停止によるシーンの無言の失敗を防ぎます。
- Finder コマンドを無効にしてもシステム拡張はアンインストールされないことと、完全な削除方法をプラグインセンターに表示します。
- バッテリーの健康度が 80% 未満、または macOS が修理を勧める場合に通知します。七日間のクールダウンは再起動後も保持し、バッテリーのない Mac では通知しません。
- 設定画面に ⌘F の全体検索、サイドバーのキーボード操作、アクセシビリティラベルを追加しました。
- クリップボード履歴で、テキスト、画像、リンク、ファイル、リッチテキスト、PDF ごとに保存期間を設定できます。
- Finder 拡張機能とメインアプリのバージョン表示を 1.1.6 に統一しました。
- Finder コンテキストメニューの診断でアクセシビリティ権限とオートメーション権限を区別し、実際の設定保存先の書き込み可否だけを表示します。
