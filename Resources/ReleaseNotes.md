# 更新说明

## 1.1.6 — 开发中

开发中：本版本内容持续补充，发布前会据此生成 Release 说明
- 修复：暂停记录后主面板与历史列表会显示「记录已暂停」徽标（此前只有隐私页那个开关本身知道状态，用户几天后发现历史不增长会以为功能坏了），悬停提示说明在哪恢复
- 修复：剪贴板「立即同步」此前只看口令输入框是否为空，已把口令存进钥匙串的用户每次同步都要重新输入；现在有钥匙串口令即可直接同步，并在输入框下提示「口令已保存到钥匙串」
- 新增：剪贴板历史支持「按内容类型分别保留」（文本/图片/链接/文件/富文本/PDF 各自设天数）。该能力早已实现并持久化，此前没有任何界面入口，而图片正是最容易撑爆容量的一类

## 1.1.5 — 2026-09-28

- 修复：内存「已用」此前按 `total - free` 计算，把文件缓存算成已用，导致面板、菜单栏、资源历史与内存告警读数长期虚高（本机实测 94.8%，实际约 70.2%）、压力恒为「临界」并常驻红色「释放内存」按钮；现按「活跃 + 常驻 + 压缩」统计，压力改为读取内核信号，只有读不到时才回退比例判定
- 修复：「锁定屏幕」此前执行的 `CGSession` 路径在 macOS 26 上已被系统移除，点击只会报错；现改用 `login.framework` 的私有符号（不需要任何权限），旧版路径保留为老系统回退，两个通道都不可用时给出可读提示而不是系统错误
- 修复：导入备份后功能中心仍显示旧开关，且随后任意开关操作会把旧状态回写、覆盖刚导入的配置；现在导入后会立即重新载入插件配置并对齐运行时
- 修复：未授予屏幕录制权限时不再静默回退命令行采集（那只会拿到桌面/墙纸图却被判为成功并进入历史与快捷卡片），改为明确报错并在设置页给出直达系统设置的按钮
- 修复：睡眠定时结束后主音量会被永久压在 0% 且没有恢复入口；结束提示里新增「恢复到定时前」（选「知道了」表示接受静音），停用音频模块时也会取消定时并恢复音量
- 修复：菜单栏统一选择器此前无条件列出全部指标，在功能中心停用某模块后选中它的指标「什么也不显示」且没有解释；现在停用模块的指标不可选并给出说明
- 修复：窗口管理、应用启动器、翻译三处设置页的辅助功能权限提示不一致（前两处只有静态文字、没有跳转入口，翻译页完全没有提示）；统一为同一组件，去系统设置授权后切回应用会自动刷新
- 修复：截图与区域 OCR 的全局快捷键失败此前只写状态字段、没有任何提示，用户只看到「按了没反应」；现在会弹出失败原因
- 修复：迁移到 SQLite 时留下的旧 JSON 与 `.migrated` 安全备份此前没有任何清理代码，会在数据目录里长期占上百 MB（本机实测 116 MB）；现在启动时按 7 天保留期清理，且仅在替代库确实存在时才删
- 修复：配置场景只施加不回滚——演示模式开启防休眠与隐藏桌面图标后没有退出入口，防休眠电源断言只能手动去关（「用完忘记 → 合盖不睡、电池跑空」）；现在场景卡片提供「退出场景」，按施加前的值还原可逆动作并释放防休眠，打开的应用与专注模式不参与回滚
- 场景改为逐动作报告失败，不再遇错即中断、只抛第一条；场景快捷键通过快捷键触发时也会弹出结果或失败原因
- 新增：主面板「工具」分类加入窗口管理入口，点开即用布局/吸附/预设（此前默认安装下鼠标完全不可达，只能先手动配一个全局快捷键），并补齐快速面板的键盘操作（搜索框回车套用第一个匹配布局、Esc 关闭）
- 新增：主面板加入 App 启动器入口（搜索启动、收藏、最近使用）。此前「收藏」在界面上没有任何写入入口，收藏集合永远为空，连「工作模式打开收藏 App」都是空操作
- 修复：窗口布局与预设的全局快捷键失败时只写状态字段（只有设置页在屏才看得到），现在会弹出失败原因；窗口自动应用规则此前用 `try?` 完全吞错，现在会记录失败原因
- 新增：权限与运行状态中心加入「全局快捷键」总览，汇总窗口布局/预设/快速面板、场景、启动器、截图、剪贴板、音量等全部绑定，并按实际按键标出重复
- 安全修复：Finder 右键命令通道增加来源校验。命令走分布式通知，通知名是公开字符串，此前任何本地进程都能伪造一份命令让主进程去执行文件操作；现在载荷必须带 0600 权限的通道令牌，缺失或不匹配的命令一律拒绝
- 性能：系统监控的采样此前在主线程同步读取 IOKit/getifaddrs/进程信息（面板打开时每 2 秒一次），会卡住面板滚动与菜单栏标题刷新；现在读取放到后台线程，主线程只做合并与告警，并合并高频档下的并发请求
- 内存读数口径变化后，资源历史里旧数据的尺度与新的不同：清除历史或等待新采样即可，趋势本身不受影响

## 1.1.4 — 2026-09-28

- 新增「系统监控」插件：CPU、内存压力与一键释放独立成可单独开关的模块（此前绑在「系统信息」里）；关闭插件会停止采样并清掉读数
- 面板资源卡改用单例保活，修掉每次打开面板 CPU 首帧为 0 的问题；「系统信息」描述改为只覆盖网络、电池、显示器、存储与蓝牙设备电量
- 系统资源指标补齐：每核 CPU 占用、内存分区明细（锁定/活跃/压缩/缓存/空闲）、磁盘读写速率、占用最高的进程（CPU/内存/磁盘，支持排序与搜索）
- 面板资源卡新增磁盘读写、内存明细与每核占用小条、占用最高的三个进程，并可直接进入「系统监控」设置页（概览 / 进程）
- 新增资源历史与告警：按分钟聚合的资源历史（SQLite + WAL，30 天保留，与网络流量共用同一套历史库设施与容量上限）；CPU 持续高位 / 内存压力临界 / 磁盘剩余不足三类通知告警，可分别设置阈值与持续时间、遵守冷却，设置页显示通知授权状态
- 设置页新增「历史」页：CPU / 内存 / 磁盘读写趋势图（1 小时 / 1 天 / 1 周 / 1 个月，超出范围自动合并桶），鼠标悬停给出该时刻三项数值，附平均与峰值、存储占用与一键清除
- 修复：历史趋势图在 1 周 / 1 月范围下柱子过多被挤压重叠（看起来「连在一起」）；柱数改为与网络流量图表一致（60/72/84/60），并保证「柱宽 × 柱数 + 间距 ≤ 可用宽度」这一不变量，悬停也改为落在空隙时不命中
- 释放内存不再弹出管理员授权：「释放内存」一键只回收本进程可安全回收的缓存（不需要任何权限）；需要管理员密码的系统文件缓存清理拆成设置页里单独标注的操作，取消授权不再误报「释放失败」
- 新增菜单栏内容统一选择器（通用设置）：网速 / 音量 / CPU / 内存 / 磁盘 / 不显示互斥，默认「按模块设置」沿用旧的网速优先其次音量；百分比固定三位宽避免菜单栏标题抖动
- 新增资源「数据源自检」：逐步检查 CPU/内存（含每核）、磁盘容量、进程列表、历史库、采样档位、通知授权与可选指标，给出结论与建议
- 可选指标：GPU 占用可读时显示；温度走 AppleSMC 只读探测，系统不提供时自动隐藏（附 Scripts/test_gpu_utilization.swift 与 Scripts/test_smc_temperature.swift 回归脚本）
- 采样改为真正的分级档位：面板打开 2 秒、仅菜单栏或告警 10 秒、都不需要则完全停止（此前插件启用后会一直 2 秒采样，且关闭一次面板就彻底停掉）
- 新增「系统存储」模块：除 DerivedData、缓存、日志与下载目录外，新增 Xcode Archives / iOS Device Support / Core Simulator 三类开发者文件统计与说明，并标注哪些可安全清理、哪些需手动确认
- 存储扫描改为分批发布结果，显示当前分类、完成进度并可随时取消；结果带缓存，重新进入页面先显示上次结果再在后台更新
- 新增清理建议（长期未使用的开发者文件、长期未整理的下载文件）与大文件列表（可在「最大文件 / 长期未使用」间切换，仅供查看和在 Finder 中定位），开发者文件支持勾选多个条目一次性清理，Xcode 正在运行或模拟器数据会先给出提示
- 面板存储卡不再固定 30 秒轮询（此前会在扫描未完成时就取消重来），改为打开面板时扫描一次、之后由用户显式刷新，扫描中可直接取消；清理入口收敛到设置页的条目管理
- 新增「权限与运行状态」中心：集中查看辅助功能、自动化、蓝牙、通知、屏幕录制等系统授权的实际状态，以及各功能插件的运行 / 需处理 / 已停用情况与原因，并可一键跳到对应设置页
- 修复：蓝牙耳机进通话模式（HFP）后输出设备只剩 1 个声道，而进程 tap 固定是立体声，App 音量此前会判为「音频通道数不一致」并放弃接管（面板出现橙色提示）；现在按声道映射自动下混或复制，输入 2 声道 / 输出 1 声道、以及 5.1 这类更宽的输出都能正常调节音量
- 修复：建路由失败后此前会永久停在失败状态，即使耳机切回音乐模式也不会恢复；现在布局与格式类失败按 2→30 秒退避重试，权限被拒等需要用户处理的问题不自动重试

- 模块更名，让名字跟上现在的功能：音量 → 音频、截图 → 截图与标注、平滑滚动 → 滚动增强、网络流量 → 网络监控、系统资源 → 系统监控、右键工具 → Finder 右键菜单；侧边栏、页内标题与功能中心卡片统一，功能中心在侧边栏与页内都叫「功能中心」（仅文案调整，不影响已有设置、快捷键绑定与数据）

- Finder 右键增强：新增可编辑内容模板、常用应用、剪贴板文本 / 图片保存、常用目录多选复制 / 移动，以及更多路径格式和 SHA-256 比对；新建前可命名、重名自动编号、完成后在 Finder 选中。
- Finder 菜单按选择内容显示，支持开关与排序；新增配置纳入备份，操作失败明确提示，主程序退出后可自动唤醒处理。
- Finder 右键菜单支持当次选择已安装的终端，保留默认终端入口；文件名与路径复制项集中到“复制”子菜单。
- Finder 右键新增可取消的传输进度、最近操作撤销、文件内容复制、目录列表 / 树形复制、常用应用类型筛选，以及日期 / 时间 / 目录 / 项目模板变量。
- Finder 右键新增批量重命名预设（正则、序号、日期、扩展名，执行前预览并支持撤销）、文件信息复制（纯文本 / Markdown / JSON）、UUID / 剪贴板 / 用户输入模板变量，以及可配置深度、隐藏文件和忽略规则的 Markdown / JSON 目录清单。
- 修复：Finder 扩展已经注册、但公开 API 在部分系统版本上暂时返回未启用时，会被误报为「未启用」；现在会回退核对系统插件注册记录，状态区分「已启用 / 已在系统中注册 / 未启用 / 等待系统确认」，并新增「刷新」按钮与扩展管理入口说明，健康检查的跳转也改为直接打开系统的扩展管理界面。

## 1.1.3 — 2026-09-15

- 音量设置页重构为四个一级页面：**调音台**（系统音量、麦克风、分组推子、正在发声/已记住的 App）、**设备**（输出/输入设备选择、声道测试、麦克风与会议自检）、**场景**（预设、自动化、预设同步）、**设置**（开关、上限与听力保护、会议压低、睡眠定时、通知、自检与诊断），默认进入调音台
- 调音台按「正在发声 / 已记住」分区：默认只显示正在发声的 App，搜索或筛选时自动带出匹配的已记住 App；空列表区分「没有 App 在发声」与「筛选无结果」
- 修复：分组音量与睡眠定时两块设置此前被插进了「听力保护」「会议压低」内部，导致标题与内容错位
- 新增「预设同步」：把预设、自动化规则与自定义 EQ 通过共享文件夹里的加密文件同步到其他 Mac（iCloud Drive、Dropbox 等）；口令存钥匙串，删除会同步传播，删除后重建的条目仍保留
- 抽出通用共享目录同步与口令加密信封，剪贴板同步与预设同步共用同一套实现（剪贴板原有文件格式与行为不变）
- 音量设置新增「分组音量」推子：一次调整浏览器 / 会议 / 游戏 / 其他整组的音量，并可整组静音与恢复
- 音量设置新增「声道测试」：左右与双声道正弦测试音（带淡入淡出与幅度上限），用来确认音箱左右接线
- 诊断页新增「自检」：按权限 → 输出设备 → 输入设备 → 路由状态 → 错误记录逐步给出结论与处理建议
- 预设的「按输出设备记忆」补齐界面：新增绑定总览（设备名、绑定的预设、未连接提示与一键解除），预设行上也会显示绑定设备
- 新增「睡眠定时」：可选 15–120 分钟，最后 30 秒把主音量线性渐弱到 0 后静音，可随时取消并恢复原音量
- 新增「不接管此 App 的音频」：跳过路由不建立 Process Tap，省 CPU，也绕开 DRM 类音源；恢复接管后按当前设置重建路由
- 修复：App 配置里的声像、单声道与不接管此前写不进本地配置（旧的字段表漏了它们），重启后会丢失；同时修正后端只看声像时不肯建立路由的问题
- 修复：菜单栏显示「音量最高的 App」时，调节音量会让菜单栏标题宽度变化，导致音量弹窗跟着抖动；现在百分比固定三位宽、App 名截断并有上限、静音也用等宽占位
- 修复：进程 tap 给出交错缓冲、而输出设备是非交错时（例如 LX Music），此前会连续失败并被误报为「格式不支持」；现在按声道映射，兼容两种布局，声道数真正不一致时给出明确原因
- 修复：某台 App 指定的输出设备已不存在时（蓝牙耳机换档会改变设备 UID），此前会永久报「已选设备不可用」且不再接管；现在会自动清掉失效指定、回退到系统默认设备并提示
