## 备注：屏数实测（改造前 → 改造后）

设置窗口详情区可视高度：系统监控 534pt、音频 568pt。

| 页面 · 子页 | 改造前 | 改造后（实测） | 结论 |

| 系统监控 · 历史 | 534pt ≈ 1.0 屏 | 534pt ≈ 1.00 屏 | 未改动 |
| 系统监控 · 告警与自检（新增） | — | 570pt ≈ **1.07 屏** | ✓ |
| 音频 · 设置 | 1714pt ≈ 3.0 屏 | 749pt ≈ **1.32 屏** | ✓ |
| 音频 · 高级（新增） | — | 571pt ≈ **1.01 屏** | ✓ |
| 音频 · 调音台 | 748pt ≈ 1.3 屏 | 764pt ≈ 1.35 屏 | 未改动 |
| 音频 · 设备 | 670pt ≈ 1.2 屏 | 670pt ≈ 1.18 屏 | 未改动 |
| 音频 · 场景 | 568pt ≈ 1.0 屏 | 568pt ≈ 1.00 屏 | 未改动 |

测量方式：用辅助功能接口打开设置窗口，逐个切换子页，取详情区滚动区域所有可见元素的 y 范围作为内容高度，除以可视高度得到屏数。

**音频页的四次处理与当前组成**：
1. 先用「显示高级设置」开关收起会议闪避/睡眠定时/自检/诊断 → 1714pt → 1061pt
2. 再把低频四项拆成独立的「高级」子页 → 设置页约 1000pt
3. 把「听力保护」也移到高级页、通知的「按类型开关」收成折叠 → 设置页 749pt
4. 高级页因此堆到 5 个分区（916pt ≈ 1.61 屏），再把只读的「自检」与「诊断」收成折叠 → 高级页 571pt

最终组成：

| 子页 | 内容 | 实测 |
|---|---|---|
| 设置 | 控制（快捷键 8 个动作 + 录制）、通知（权限行常显，按类型开关默认收起） | 1.32 屏 |
| 高级 | 听力保护、会议闪避、睡眠定时、自检（默认收起）、诊断（默认收起） | 1.01 屏 |

**两组数值会随实际数据变化**：调音台取决于当前有声会话数、设备页取决于连接的输出/输入设备数，空闲与满载时相差可达 100pt 左右。

**测量方式**：用辅助功能接口打开设置窗口 → 逐个切换子页 → 取详情区滚动区域所有可见元素的 y 范围作为内容高度，除以可视高度得到屏数（系统监控可视 534pt、音频可视 568pt）。探针脚本 `Scripts/` 下没有，是临时脚本；如需长期回归可考虑固化成 `Scripts/test_settings_layout.swift`。
