## 系统监控（设置 → 系统监控）

### 页面结构

- [x] 顶部分段为「概览 / 进程 / 历史 / 告警与自检」
- [x] 从已滚动到底部的进程页切至历史页后，历史页从顶部显示时间范围与指标

### 概览

- [x] CPU 卡显示总占用率，展开「各核心占用」后显示 10 核占用条；内存卡显示「已用 / 总量」和压力
- [x] 「内存明细」默认收起，展开后显示锁定、活跃、压缩、缓存、空闲
- [x] 「内存明细」保持收起时，独立展开「内存工具」仍能看到「回收可用内存」和「清理系统文件缓存…」；工具区本身默认收起
- [x] 磁盘和网络卡显示实时读数；告警配置与自检步骤在「告警与自检」页

### 进程与历史

- [x] 进程列表默认只显示前 8 项；「显示全部 20 项」可展开，底部按钮可收回 8 项
- [x] 搜索 `Codex` 显示超过 8 个命中项，清空后回到 8 项预览
- [x] 从 CPU 切换到内存排序后列表顺序变化，收起后仍只预览 8 项
- [x] 历史页从 1 小时切到 1 天、从 CPU 切到内存，图表及统计值随之更新

### 告警与自检

- [x] 显示告警开关、通知授权状态、CPU/磁盘阈值与自检结果；当前通知尚未授权
- [ ] 关闭告警后阈值控件收起；重新开启后设置仍保留
- [ ] 修改阈值后切到其他子页再返回，设置不丢失

## 音频（设置 → 音频）

### 页面结构

- [x] 顶部分段为「调音台 / 设备 / 场景 / 设置 / 高级」，重新进入音频页默认显示调音台
- [x] 调音台显示当前输出、输入与分组音量；设备页显示输出/输入设备；场景页显示预设空状态，三个子页均可切换

### 设置与高级

- [x] 「设置」页包含快捷键控制与通知；通知权限常显，按类型开关默认收起，展开可见三项提醒设置
- [x] 「高级」页包含听力保护、会议闪避、睡眠定时、自检与诊断
- [x] 自检与诊断默认收起；展开后显示设备、权限、路由与错误记录，点击复制后按钮变为「诊断报告已复制」
- [ ] 自检与兼容性诊断可独立开合：安装版 1.1.6 点开自检时两区同步展开；开发分支已修复并通过单元测试，待真实界面复验
- [ ] 修改会议闪避或睡眠定时后切页再返回，设置不丢失
- [ ] 在设置页开始录制快捷键，切到调音台或设备页后按组合键，返回设置页确认记录
