## 备注：屏数实测（改造前 → 改造后）

设置窗口详情区可视高度：系统监控 534pt、音频 568pt。

| 页面 · 子页 | 改造前 | 改造后 | 结论 |
|---|---|---|---|
| 系统监控 · 概览 | 1565pt ≈ 2.9 屏 | 843pt ≈ **1.6 屏** | ✓ 达标 |
| 系统监控 · 进程 | 1171pt ≈ 2.2 屏 | 604pt ≈ **1.1 屏** | ✓ 达标 |
| 系统监控 · 历史 | 534pt ≈ 1.0 屏 | 534pt ≈ 1.0 屏 | 未改动 |
| 系统监控 · 告警与自检（新增） | — | 570pt ≈ **1.1 屏** | ✓ 新页在一屏内 |
| 音频 · 设置 | 1714pt ≈ 3.0 屏 | 1061pt ≈ **1.9 屏** | ⚠️ 未达标（目标 ~1.3 屏） |
| 音频 · 调音台 / 设备 / 场景 | 748 / 670 / 568pt | 同前（1.3 / 1.2 / 1.0 屏） | 未改动 |

测量方式：用辅助功能接口打开设置窗口，逐个切换子页，取详情区滚动区域所有可见元素的 y 范围作为内容高度，除以可视高度得到屏数。

**音频设置页仍偏长的原因**：收起会议闪避/睡眠定时/自检/诊断四块约省下 650pt，剩下的「控制（快捷键）列表 + 听力保护 + 通知 + 开关行」本身就有约 1061pt。要压到一屏出头，下一步建议把低频项拆成独立的「高级」子页（而不是继续往同一个开关里塞），这样设置页只剩快捷键控制、听力保护与通知。
