# 系统监控与音频设置页验收清单

> 这两处改造已随 1.1.3/1.1.4 上线。以下交互仍需在当前构建中逐项复核；上线记录不能代替真实界面验收。

## 前置

- [ ] 安装并启动当前构建，确认设置窗口标题和应用版本正确
- [ ] 系统监控有实时采样数据
- [ ] 音频快捷键录制所需的辅助功能权限已授权

## 系统监控（设置 → 系统监控）

### 页面结构

- [ ] 顶部分段为「概览 / 进程 / 历史 / 告警与自检」
- [ ] 切换子页后从顶部开始，不继承上一页的滚动位置

### 概览

- [ ] CPU 卡显示总占用率与各核心占用条；内存卡显示「已用 / 总量」和压力
- [ ] 「内存明细」默认收起，展开后出现 wired / active / compressed / cached / free
- [ ] 「释放内存」与「清理系统缓存」按钮不随明细收起而消失
- [ ] 磁盘和网络卡正常显示；告警配置与自检步骤不出现在概览页

### 进程与历史

- [ ] 进程列表默认只显示前 8 项；「显示全部」可展开与收起
- [ ] 搜索时显示全部命中项，清空搜索后回到 8 项预览
- [ ] 切换排序后顺序变化，预览条数规则不变
- [ ] 历史页可切换时间范围与指标，图表可见

### 告警与自检

- [ ] 显示告警开关、通知授权状态、阈值与自检结果
- [ ] 关闭告警后阈值控件收起；重新开启后设置仍保留
- [ ] 修改阈值后切到其他子页再返回，设置不丢失

## 音频（设置 → 音频）

### 页面结构

- [ ] 顶部分段为「调音台 / 设备 / 场景 / 设置 / 高级」，默认进入调音台
- [ ] 调音台、设备与场景页正常显示当前数据并可切换

### 设置与高级

- [ ] 「设置」页包含快捷键控制与通知；通知权限常显，按类型开关默认收起
- [ ] 「高级」页包含听力保护、会议闪避、睡眠定时、自检与诊断
- [ ] 自检与诊断默认收起；展开后内容可读，「复制诊断报告」有成功反馈
- [ ] 修改会议闪避或睡眠定时后切页再返回，设置不丢失
- [ ] 在设置页开始录制快捷键，切到调音台或设备页后按组合键，返回设置页确认记录

## 回归

- [ ] 菜单栏浮层中的系统资源卡与音频快速面板仍正常工作
- [ ] 离开资源页后停止该页专属采样；离开音频相关页面后停止输入电平监测
- [x] `swift test`：2026-09-29 在 1.1.6 分支执行，1035 项通过（单元测试，非界面验收）
