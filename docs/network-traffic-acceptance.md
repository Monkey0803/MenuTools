## 出问题时

1. 先在「诊断」页看采样耗时、失败次数与失败原因；界面上的 App/速率/连接都来自同一个 `nettop` 输出，诊断异常时先修采样再查界面
2. 跑 `swift Scripts/test_network_traffic.swift --duration 30 --connections --strict`：确认 nettop 是否可用、输出字段是否随系统升级变化
3. 提醒不送达时先看设置页的通知授权状态行，再去「系统设置 → 通知 → MenuTools」确认
4. 把「诊断页截图 + 复现步骤 + 期望结果」一起反馈；涉及历史数据的问题请注明当前网卡/协议筛选维度
