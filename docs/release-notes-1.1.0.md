# MenuTools 1.1.0

> 本文件是 v1.1.0 GitHub Release 的正文来源（发布时整段复制，或 `gh release create --notes-file docs/release-notes-1.1.0.md`）。
> 如果重新打包（`./release.sh`），请同步更新文末的 SHA-256。

**系统要求**：macOS 26 或更高版本 · Apple 芯片（arm64）

## 安装

- `MenuTools-1.1.0.dmg`：打开后把 `MenuTools.app` 拖入「应用程序」
- `MenuTools-1.1.0.zip`：解压后把 `MenuTools.app` 拖入「应用程序」
- 源码：由 GitHub 按 tag 自动提供（Source code zip / tar.gz）

## 更新内容

### 网络流量（新模块）

- 按 App 显示实时上下行速率、连接明细和 30 天历史趋势，面板卡片可直接进入
- 概览 / App / 历史 / 诊断四个视图，支持网卡、协议、App 与时间范围筛选，以及搜索和排序
- 流量额度提醒与系统通知，设置页显示通知授权状态并可直接跳转系统设置
- 历史趋势支持悬停查看某一时刻的上下行明细
- 采样可暂停与继续；诊断页暴露采样耗时、失败次数、失败原因和历史存储占用
- 脱敏导出与数据清理；停用「网络流量」插件时会一并停止采样

### 剪贴板

- 本地历史加密存储：SQLite 元数据与二进制内容分离，带库结构版本校验与迁移
- 支持文本、富文本、图片、链接、文件和 PDF；图片文字与二维码在本地识别（进程级串行闸门 + 失败自动重试 + 面板手动重试）
- 搜索、分类/来源/时间筛选、置顶、批量置顶与敏感标记、多选删除与撤销
- 应用策略：按 bundle ID 覆盖记录与粘贴行为，可暂停记录、排除指定应用
- 敏感内容规则：密码管理器、验证码、银行卡与自定义关键词；命中的内容不持久化并限时过期
- 常用片段：分组、标签、收藏、模板变量与拖拽排序
- 顺序粘贴队列（单次/循环）、文本变换、快捷面板数字键 1–9 直接粘贴、历史条目可拖拽到其他 App
- 共享文件夹同步：置顶内容与片段跨设备合并，支持按间隔自动同步；删除、取消置顶、重命名与收藏等状态都会同步（删除墓碑保留 30 天）
- 同步写入前校验文件指纹，被其他设备改写时带新内容重新合并；持续争用时写出冲突副本并在设置页提示

### 窗口管理

- 边缘吸附：窗口贴住屏幕边缘即可吸附，带落点预览生长动画、可选的精细吸附区域与触觉反馈
- Loop 式边缘收纳与收回；把已吸附窗口拖出可恢复原尺寸
- 布局循环、吸附预览与自动还原；布局预设支持固定尺寸和全局快捷键绑定
- 应用规则支持限定主窗口、按标题过滤与跳过弹窗
- 支持 `menutools://` 链接触发窗口操作；诊断日志按需开启

### 本地化与质量

- 五种语言（简体中文 / 繁体中文 / 英语 / 日语 / 韩语）文案补齐，并新增四道自动校验：代码引用文案完整性、重复键、硬编码中文、格式符跨语言一致性
- 新增剪贴板系统能力验证脚本 `Scripts/test_clipboard_autopaste.swift`
- 修复共享文件夹同步、音量条拖动排序跳动、MX Master 2S 后台滚动跟手性、全局快捷键事件泄漏等问题

### 发布与构建

- `release.sh` 支持两种发布模式：GitHub 自签名分发（默认，产出 ZIP + DMG + Sparkle appcast）与 Developer ID 公证分发
- Finder 扩展改用当前活动 Xcode 的 SDK 编译

## 签名说明

本版本使用项目自签名证书 `MenuTools Self-Signed`，**未使用 Apple Developer ID，未经过 notarization**。首次打开如被 macOS 阻止，请按 README 的「首次打开」说明操作（系统设置 → 隐私与安全性 → 仍要打开）。

已安装 1.0.x 的用户可以直接通过应用内更新升级到 1.1.0：`appcast.xml` 已用与 App 内嵌公钥配对的 Ed25519 私钥签名。
