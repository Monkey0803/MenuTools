## 更新内容

- 修复：内存「已用」此前按 `total - free` 计算，把文件缓存算成已用，导致面板、菜单栏、资源历史与内存告警读数长期虚高（本机实测 94.8%，实际约 70.2%）、压力恒为「临界」并常驻红色「释放内存」按钮；现按「活跃 + 常驻 + 压缩」统计，压力改为读取内核信号，只有读不到时才回退比例判定
- 修复：「锁定屏幕」此前执行的 `CGSession` 路径在 macOS 26 上已被系统移除，点击只会报错；现改用 `login.framework` 的私有符号（不需要任何权限），旧版路径保留为老系统回退，两个通道都不可用时给出可读提示而不是系统错误
- 修复：导入备份后功能中心仍显示旧开关，且随后任意开关操作会把旧状态回写、覆盖刚导入的配置；现在导入后会立即重新载入插件配置并对齐运行时
- 修复：未授予屏幕录制权限时不再静默回退命令行采集（那只会拿到桌面/墙纸图却被判为成功并进入历史与快捷卡片），改为明确报错并在设置页给出直达系统设置的按钮
- 修复：睡眠定时结束后主音量会被永久压在 0% 且没有恢复入口；结束提示里新增「恢复到定时前」（选「知道了」表示接受静音），停用音频模块时也会取消定时并恢复音量
- 修复：菜单栏统一选择器此前无条件列出全部指标，在功能中心停用某模块后选中它的指标「什么也不显示」且没有解释；现在停用模块的指标不可选并给出说明
- 修复：窗口管理、应用启动器、翻译三处设置页的辅助功能权限提示不一致（前两处只有静态文字、没有跳转入口，翻译页完全没有提示）；统一为同一组件，去系统设置授权后切回应用会自动刷新
- 修复：截图与区域 OCR 的全局快捷键失败此前只写状态字段、没有任何提示，用户只看到「按了没反应」；现在会弹出失败原因
- 修复：迁移到 SQLite 时留下的旧 JSON 与 `.migrated` 安全备份此前没有任何清理代码，会在数据目录里长期占上百 MB（本机实测 116 MB）；现在启动时按 7 天保留期清理，且仅在替代库确实存在时才删
- 修复：配置场景只施加不回滚——演示模式开启防休眠与隐藏桌面图标后没有退出入口，防休眠电源断言只能手动去关（「用完忘记 → 合盖不睡、电池跑空」）；现在场景卡片提供「退出场景」，按施加前的值还原可逆动作并释放防休眠，打开的应用与专注模式不参与回滚
- 场景改为逐动作报告失败，不再遇错即中断、只抛第一条；场景快捷键通过快捷键触发时也会弹出结果或失败原因
- 新增：主面板「工具」分类加入窗口管理入口，点开即用布局/吸附/预设（此前默认安装下鼠标完全不可达，只能先手动配一个全局快捷键），并补齐快速面板的键盘操作（搜索框回车套用第一个匹配布局、Esc 关闭）
- 新增：主面板加入 App 启动器入口（搜索启动、收藏、最近使用）。此前「收藏」在界面上没有任何写入入口，收藏集合永远为空，连「工作模式打开收藏 App」都是空操作
- 修复：窗口布局与预设的全局快捷键失败时只写状态字段（只有设置页在屏才看得到），现在会弹出失败原因；窗口自动应用规则此前用 `try?` 完全吞错，现在会记录失败原因
- 新增：权限与运行状态中心加入「全局快捷键」总览，汇总窗口布局/预设/快速面板、场景、启动器、截图、剪贴板、音量等全部绑定，并按实际按键标出重复
- 安全修复：Finder 右键命令通道增加来源校验。命令走分布式通知，通知名是公开字符串，此前任何本地进程都能伪造一份命令让主进程去执行文件操作；现在载荷必须带 0600 权限的通道令牌，缺失或不匹配的命令一律拒绝
- 性能：系统监控的采样此前在主线程同步读取 IOKit/getifaddrs/进程信息（面板打开时每 2 秒一次），会卡住面板滚动与菜单栏标题刷新；现在读取放到后台线程，主线程只做合并与告警，并合并高频档下的并发请求
- 内存读数口径变化后，资源历史里旧数据的尺度与新的不同：清除历史或等待新采样即可，趋势本身不受影响
