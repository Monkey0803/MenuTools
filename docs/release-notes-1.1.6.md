## 更新内容

- 修复：暂停记录后主面板与历史列表会显示「记录已暂停」徽标（此前只有隐私页那个开关本身知道状态，用户几天后发现历史不增长会以为功能坏了），悬停提示说明在哪恢复
- 修复：剪贴板「立即同步」此前只看口令输入框是否为空，已把口令存进钥匙串的用户每次同步都要重新输入；现在有钥匙串口令即可直接同步，并在输入框下提示「口令已保存到钥匙串」
- 修复：剪贴板历史的「条目数上限」从「筛选」菜单移到管理区（它是保留策略而不是筛选条件），改一次容量不再显示成「筛选已生效 1」
- 新增：剪贴板图片的文字/二维码识别可整体关闭（隐私页开关）。此前识别无条件排队、没有任何开关；关闭后不再识别并清掉已保存的识别结果，图片本身仍保留在历史里
- 新增：剪贴板管理区显示磁盘实际占用（数据库 + 回退备份 + 图片/PDF 附件）并提供「立即清理」；清理会按保留策略裁剪、收缩数据库并把回退备份同步成收缩后的副本（此前占用完全不可见，而自动清理是唯一会自行发生却看不到的机制）
- 修复：平滑滚动设置页显示运行状态。此前开关打开、权限也给了、事件监听却没装上时没有任何提示，用户只看到「没效果」；现在区分「监听中」「需要辅助功能权限」「监听未启动」
- 安全修复：常用片段此前以明文 JSON 落盘（用户会把 token、命令存进片段），现在与历史库一样用 AES-GCM 加密，旧明文文件仍能读入并在下次使用片段时就地回写为密文
- 修复：反复拖动音频均衡器会让内部配置数组无限增长（长会话内存单调上升）；现在只滚动保留最近两份，既不再增长，也不让音频回调读到已释放的内存
- 修复：资源告警的冷却时间此前只存在内存里，应用重启后同一件已经提醒过的事会立刻再提醒一次（磁盘剩余不足的冷却长达 24 小时）；现在冷却会写入偏好并在启动时恢复
- 修复：系统监控的百分比口径统一（此前设置页把上界夹到 99%，满载也显示 99%，而菜单栏按 0...1 计算，同一读数两处不一致）；历史柱与每核条此前只有鼠标悬停能看数值，现在可用左右方向键浏览并对 VoiceOver 可读
- 新增：`menutools://` 链接触发扩展到场景（`scene?name=demo`）与快捷操作（`quick-action?name=lock-screen`），此前只能触发窗口布局、预设与设置页，场景与快捷操作无法被 Raycast/快捷指令调用
- 修复：链接名转换此前给每个大写字母都补连字符，`flushDNS` 变成 `flush-d-n-s`，脚本按 `flush-dns` 调用会直接解析失败
- 修复：设置页的操作结果提示统一为同一套（绿=成功、红=失败、灰=信息）。此前存储页把「已清理」和报错都显示成灰色（出错看起来像成功），翻译页只有一行红字，截图页用两个状态量成对赋值
- 新增：截图标注器支持键盘操作（⌘Z 撤销、⇧⌘C 复制识别文字、⌘⌫ 清空标注、⌘S 保存、Esc 取消）并补齐图标按钮的无障碍标签
- 修复：截图历史在设置页固定只显示 8 条（实际保留 50 条），其余 42 条在界面上完全看不到；现在可搜索文件名、可展开全部，并显示拍摄时间；清空记录增加二次确认并说明不会删除磁盘上的图片
- 修复：截图标注器此前「撤销」只能退掉最后一个标注，而裁剪与旋转会直接清空全部标注且不可恢复、也没有重做；现在裁剪、旋转、清空、新增标注都进入撤销栈（⌘Z / ⇧⌘Z），截图最多保留最近 30 步
- 修复：平滑滚动的「本进程有可见窗口时放行原始事件」判断此前从未接线（参数一直用默认 false），导致不抢前台的快速面板里滚动会被全局钩子改写；现在按可见且有内容尺寸的窗口判定，并排除状态栏按钮自身
- 新增：单 App 音量在「正在处理却持续无声」超过 5 秒时提示可能是受保护音源（DRM）导致，只提示、不改动音频行为；判据未经真机验证，已在 README 的已知限制里写明
- 修复：Finder 右键菜单此前只按系统语言显示，与「设置 → 语言」里手动选择的语言无关，非中文系统下会出现「主界面英文、右键菜单中文」；现在应用内语言随共享配置下发给扩展，切换语言后即时生效
- 性能：Finder 右键菜单每次构建都会重做剪贴板图片的 TIFF 解码 + PNG 重编码、并对 6 个终端各查一次 LaunchServices，多选或大截图时可能让菜单空白；现在剪贴板按 changeCount 缓存、终端安装状态进程内只查一次，并给图片解码加上限
- 改进：插件中心显示「依赖」与「被谁依赖」（停用会被拒绝并说明原因）；自动化插件声明了对启动器与系统控制插件的真实依赖，避免「工作模式打开收藏 App」变成静默空操作、以及停用系统控制插件后场景的防休眠被静默取消
- 说明：Finder 扩展无法由应用自行卸载，插件中心现在会如实说明「停用只停止命令处理，扩展在系统设置里仍是启用状态」以及彻底移除的位置
- 新增：电池健康告警（健康度低于 80% 或系统提示维修时提醒一次，冷却 7 天并跨重启保留）。告警面此前只覆盖 CPU/内存/磁盘；无电池的桌面 Mac 静默降级
- 新增：设置页支持全局搜索（⌘F 聚焦，按页面标题或 `runtime-status` 这类英文别名匹配，回车跳到第一条结果），侧边栏可用上下方向键切换页面，并补齐侧边栏与图标网格的无障碍标签
- 新增：剪贴板历史支持「按内容类型分别保留」（文本/图片/链接/文件/富文本/PDF 各自设天数）。该能力早已实现并持久化，此前没有任何界面入口，而图片正是最容易撑爆容量的一类
- 修复：Finder 右键扩展的版本号与主程序同步为 1.1.6，避免安装包内出现两个不同版本号
- 修复：右键健康检查将辅助功能权限与自动化权限分清；未授权时提供直达辅助功能设置的按钮，配置卡只报告实际存储目录是否可写
