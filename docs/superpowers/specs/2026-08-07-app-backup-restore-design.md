# 应用配置备份与恢复设计

## 目标

在 `1.0.1` 分支为 MenuTools 增加应用配置的导出与导入恢复功能。用户通过保存面板选择备份文件位置，通过打开面板选择恢复文件；恢复失败时不改变现有配置。

## 备份范围

备份文件只包含应用拥有的用户配置，不复制 App 安装包、缓存或系统状态：

- 菜单栏图标、菜单栏标题显示、面板标题显示。
- 默认终端、自动更新开关、应用语言。
- 全部平滑滚动配置，包括启用状态、轴向选项、增益、动画时长、最小步长、触控板模拟和三个修饰键。
- Finder 右键工具各菜单项的启用状态。

以下数据不进入备份：

- 更新检查时间和测试用更新源覆盖地址。
- Finder、Dock、菜单栏、系统外观等系统级实时状态。
- 蓝牙电量、缓存、临时状态和权限授权状态。

## 文件格式

备份文件使用 JSON 编码，扩展名为 `.menutoolsbackup`。顶层包含格式版本、创建时间、应用版本和固定结构的配置快照：

```json
{
  "formatVersion": 1,
  "createdAt": "2026-08-07T00:00:00Z",
  "appVersion": "1.0.1",
  "settings": {},
  "rightClick": {}
}
```

只恢复当前版本明确支持的字段。未知字段允许被忽略，格式版本不支持时拒绝恢复。

## 恢复安全

- 先把整个文件解码到 `AppBackupDocument`，再校验版本和数值范围。
- 所有校验完成前不写入 `UserDefaults` 或右键配置文件。
- 写入过程中使用当前配置快照作为内存回滚来源；右键 JSON 写入失败时恢复原配置。
- 恢复成功后刷新 `SmoothScrollEngine` 和界面状态。
- 备份文件来自用户选择路径，导入只处理 JSON 数据，不执行文件中的代码或路径。

## UI

在通用设置页增加“备份与恢复”区块：

- “导出备份”：打开保存面板，默认文件名为 `MenuTools-1.0.1.menutoolsbackup`。
- “导入恢复”：打开文件选择面板，只允许选择 `.menutoolsbackup` 文件，成功后刷新配置。
- 显示最近一次操作成功或失败的本地化状态。

## 验收标准

- 导出的文件可被 JSON 解码，并完整保留所有备份范围内配置。
- 合法备份可以恢复到内存和磁盘配置。
- 格式版本错误、字段非法、文件损坏或写入失败时，现有配置保持不变。
- 设置页可导出和导入，成功恢复后平滑滚动和右键工具即时使用新配置。
- Swift Testing、release build 和 App 打包均通过。
