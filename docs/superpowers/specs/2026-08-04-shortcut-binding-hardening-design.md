# 快捷键绑定可靠性修复设计

## 目标

让设置页显示的快捷键状态与实际 Carbon 注册状态一致，并让用户能识别辅助功能权限不足和快捷键注册失败。保留现有九个动作及其持久化格式，不改变与本次问题无关的功能。

## 范围

- `ShortcutManager`：注册结果、重复绑定、旧绑定恢复、事件处理器安装失败。
- `ShortcutSettingsView`：错误状态、辅助功能状态、系统设置跳转、录制器销毁清理、清除按钮无障碍标签。
- `ShortcutAction`：执行合成按键前检查辅助功能权限；对无法确认成功的动作保留现有尽力而为实现，不伪造成功状态。
- 本地化：新增错误和辅助功能提示文案。

不在本次范围内：重写听写或勿扰模式的系统调用。空间切换使用 macOS 标准的 System Events `Control+方向键`，不再依赖 SkyLight 私有 API。

## 行为设计

### 绑定流程

1. 录制得到 `KeyCombo` 后，先检查该组合是否已经绑定到其他动作。
2. 注销当前动作的旧热键，但暂不修改持久化字典。
3. 尝试注册新热键。
4. 注册成功后更新 `bindings` 并持久化。
5. 注册失败时尝试恢复旧热键和旧字典，向设置页发布用户可读错误。
6. 清除操作注销热键、删除字典值并持久化；清除本身不产生错误。

注册失败不能表现为“已设置”。错误状态在下一次成功绑定或清除后清除。

### 事件处理器

`InstallEventHandler` 只有返回 `noErr` 才标记为已安装。安装失败时不注册快捷键，并通过设置页错误状态提示用户。事件参数读取失败的事件直接忽略，不执行默认动作。

### 辅助功能

设置页显示 `AXIsProcessTrusted()` 当前状态。权限不足时显示已有滚动设置页面同款的辅助功能设置跳转按钮。权限状态用定时刷新，用户返回设置后无需重启应用即可看到变化。

执行合成按键动作前再次检查权限；无权限时返回失败结果，由管理器或设置页显示提示，而不是静默发送事件。

### 录制器生命周期

`NSViewRepresentable` 实现 `dismantleNSView`，显式调用 coordinator 的停止监听方法。开始监听前保持幂等，停止监听后清空 monitor，避免切换 Tab、语言重建或关闭窗口后旧监听器残留。

## 结构调整

- `ShortcutManager` 增加可观察的错误状态和辅助方法，使 View 不需要知道 Carbon 注册细节。
- 注册函数返回结构化结果，而不是只在成功分支写入内部字典。
- `ShortcutAction.perform()` 改为返回执行结果；应用启动类动作仍按现有 `NSWorkspace` 路径执行，无法确认的异步打开失败仅保留静默兼容，不扩展为复杂反馈系统。
- UI 只负责展示错误、权限状态和清除动作，不直接操作 Carbon。
