# 窗口管理运行时验收清单

窗口管理模块的行为大量依赖辅助功能 API、全局鼠标监听和真实拖拽，单元测试覆盖不到。这份清单用于在真机上逐项验收，覆盖「已交付但从未在真机跑过」的功能。

建议先打开诊断日志（默认不写任何文件）：

```bash
touch /tmp/menutools-snap-debug     # 下次启动后写 /tmp/menutools-snap.log
rm /tmp/menutools-snap-debug        # 验收结束后关闭
```

前置条件：

- [ ] 应用已重启到最新构建（`pkill -f MenuTools.app/Contents/MacOS/MenuTools; ./build.sh`）
- [ ] 辅助功能权限已授予（窗口管理设置页没有橙色权限提示）
- [ ] 准备两个普通窗口（例如一个浏览器窗口 + 一个文本窗口）；验收期间不要用全屏应用和台前调度

---

## 1. 拖动吸附与落点预览 ✅ 已确认（2026-09-11）

- [x] 抓窗口标题栏中部，把窗口推到屏幕左边缘后松手 → 吸附为左半屏，四周留 8pt 边距
- [x] 光标一路甩到屏幕最左边 → 拖动过程中出现半透明落点预览
- [ ] 在屏幕中部拖动窗口 → 不出现预览，松手也不吸附
- [ ] 在窗口**正文**里划选文字直到屏幕边缘 → 不出现预览（不应把划选误判成拖窗口）
- [ ] 关闭设置页「拖动窗口到屏幕边缘时自动吸附」→ 上述行为全部停止；「显示落点预览」开关在它关闭时应为禁用状态

## 2. 固定尺寸预设

- [ ] 设置页预设区输入名称 → 点「记住当前窗口」→ 列表出现带「固定尺寸」徽标的预设
- [ ] 改变窗口大小与位置后点「应用」→ 回到保存时的位置与尺寸
- [ ] 快速面板（快捷键或面板顶部）出现该预设，点击可套用
- [ ] 在外接显示器上保存预设 → 合上/断开外接显示器后套用 → 窗口被夹取回主显示器可用区域，不会留在屏幕外

## 3. 预设快捷键

- [ ] 给预设录制一个组合键 → 按一次即套用该预设
- [ ] 把同一个组合键录给某个布局 → 被拒绝，提示与窗口预设冲突（而不是静默生效）
- [ ] 删除该预设 → 其快捷键不再触发；重新打开设置页后绑定已被清理

## 4. 同族布局循环

- [ ] 给「第一列三分之一」绑快捷键 → 连按：第一列 → 中间列 → 最后一列 → 回到第一列
- [ ] 中途按一次「左半屏」再回来连按三分之一 → 循环从第一列重新开始
- [ ] 切换到另一个窗口连按 → 循环从第一列开始（不沿用上一个窗口的进度）
- [ ] 关闭设置页「连按同一快捷键循环切换同族布局」→ 连按不再切换

## 5. 自动还原

- [ ] 窗口放在任意位置 → 套用「右半屏」→ 触发「恢复」→ 回到套用**前**的位置（不需要先点「记住尺寸」）
- [ ] 从没有套用过任何布局的新窗口触发「恢复」→ 给出「还没有保存的窗口尺寸」提示，不崩溃

## 6. Loop 式边缘收纳

- [ ] 给「收纳到左边缘」绑快捷键 → 触发 → 窗口只在屏幕内留约 16pt 一条边
- [ ] 再次触发同一方向 → 窗口收回原位
- [ ] 收纳后触发「恢复」→ 同样能收回
- [ ] 对不支持越界摆放的应用 → 收纳无效但不崩溃（`Scripts/test_window_management.swift --interactive` 可验证底层能力）

## 7. 连按半屏跨显示器（默认关闭）

- [ ] 设置页开启「连按半屏布局时把窗口带到相邻显示器」（单显示器时该开关应为禁用）
- [ ] 连按「左半屏」→ 窗口移动到左侧相邻显示器并保持左半屏
- [ ] 连按「右半屏」→ 移动到右侧相邻显示器
- [ ] 关闭该开关后再连按 → 窗口不再跨显示器

## 8. 多窗口网格排列

- [ ] 同一应用开 3 个窗口 → 「排列当前应用窗口」→ 三列网格
- [ ] 其中一个是全屏窗口 → 它不被移动，其余窗口参与网格
- [ ] 排列结果符合屏幕阅读顺序（先上后下、同一行从左到右），不随 AX 返回顺序乱跳

## 9. 应用规则（可选）

- [ ] 给当前应用绑定布局 → 开启「切换应用时自动应用窗口规则」→ 切走再切回 → 自动套用该布局
- [ ] 把该应用加入排除列表 → 切回时不再自动套用

## 出问题时

1. 看 `/tmp/menutools-snap.log`（需要先 `touch /tmp/menutools-snap-debug` 并重启应用）：能看到命中测试结果、标题栏判定、预览落点、松手吸附每一步
2. 跑 `swift Scripts/test_window_management.swift --interactive`：确认辅助功能权限、多显示器几何、AX 读写是否正常
3. 把日志片段 + 复现步骤 + 期望结果一起反馈
